# Machine Learning Projects – Datheon Data Science Internship

## Overview

This repository showcases four Machine Learning projects developed as part of the **Datheon Data Science Internship**. The projects demonstrate practical applications of data science and machine learning techniques, covering data preprocessing, exploratory data analysis, feature engineering, model development, evaluation, and interpretation of results.

The projects explore different machine learning applications, including regression, classification, customer behaviour prediction, and Natural Language Processing (NLP).

## Projects

### 1. House Price Prediction – Regression

**Objective:** Develop machine learning models to predict house prices based on relevant property features.

This project explores regression techniques to understand the relationship between housing characteristics and property prices.

Key activities:
- Exploratory Data Analysis (EDA).
- Data cleaning and preprocessing.
- Feature engineering and selection.
- Regression model development.
- Model evaluation and comparison.
- Interpretation of model performance.

**Learning outcomes:** Understanding regression algorithms, feature relationships, model evaluation, and price prediction.

### 2. Iris Flower Classification – Classification

**Objective:** Develop machine learning models to classify iris flowers into their respective species using flower measurements.

The project uses the Iris dataset to explore supervised classification techniques and compare model performance.

Key activities:
- Exploratory Data Analysis.
- Data cleaning and preprocessing.
- Feature analysis and visualisation.
- Classification model development.
- Model evaluation using accuracy, precision, recall, and F1-score.
- Comparison of classification models.

**Learning outcomes:** Understanding supervised learning, classification algorithms, model evaluation, and multi-class prediction.

### 3. Customer Churn Prediction – Classification

**Objective:** Build machine learning models to predict whether a customer is likely to discontinue a service.

This project applies classification techniques to customer data to identify patterns associated with customer attrition and explore how predictive analytics can support customer retention strategies.

Key activities:
- Exploratory Data Analysis.
- Data cleaning and preprocessing.
- Handling class imbalance.
- Feature engineering and feature importance analysis.
- Classification model development and comparison.
- Model evaluation using accuracy, precision, recall, and F1-score.
- Interpretation of important churn indicators.

**Learning outcomes:** Understanding imbalanced classification, customer behaviour analysis, feature importance, and the application of machine learning in business decision-making.

### 4. Natural Language Processing (NLP)

**Objective:** Apply Natural Language Processing techniques to extract meaningful information and patterns from textual data.

This project explores the application of machine learning and text processing techniques to work with unstructured textual information.

Key activities:
- Text data exploration and preprocessing.
- Text cleaning and normalisation.
- Tokenisation and text representation.
- Feature extraction from textual data.
- Application of NLP techniques.
- Analysis and interpretation of results.

**Learning outcomes:** Understanding text preprocessing, natural language processing workflows, and machine learning applications involving textual data.

## Getting Started

To explore and run the projects locally:

**1. Clone the repository**

```bash
git clone https://github.com/Mathilo-source/Datheon_Machine_Learning_-_Data_Science_Internship.git
```

**2. Navigate into the repository**

```bash
cd Datheon_Machine_Learning_-_Data_Science_Internship
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Additional dependencies may be required depending on the individual project.

**4. Explore the project folders**

Each project contains its respective notebooks, datasets (where included), and supporting files.
